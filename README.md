# Openplanetarium

VSCode extension and language server for Openplanet's Angelscript.

## Features
- syntax highlighting (incomplete)

## Usage
- install extension from the VSCode Marketplace
- open an Angelscript source file

## Development

Read the [contributing rules](./CONTRIBUTING.md) before starting.

```
git clone https://github.com/ezio416/openplanetarium
cd openplanetarium
npm install
code .
```

Build and launch extension in a new window with `F5`
